# Methodological documentation

This directory will hold the revised English methodological PDFs for the IGES/JRC and SDGIndex procedures. The reports will be prepared after the English implementation has been reviewed.

The current repository documents the executable procedures in the root README. `english-migration.md` records the language/schema migration and official terminology sources. `legacy-schema.json` records renamed identifiers for compatibility and audit purposes.

## Methodological article (draft)

`SDG_Interlinkages_methodological_article.md` and `.docx` hold the current draft of *Beyond Co-movement: Performance Direction and Transmission Roles in SDG Interlinkage Networks*. It explains the framework implemented here: performance-based link classification, the six interface roles, context as characterisation, and the link-share weighted version for IGES/JRC. It includes a synthetic worked example (reproduced in `tests/test_roles.py`) and an application to Brazil's SDG Index components. Figures are in `figures/`. The draft is experimental and preliminary; open items are listed in the root `TODO.md`.
