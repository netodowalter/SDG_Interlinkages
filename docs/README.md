# Methodological documentation

This directory will hold the revised English methodological PDFs for the IGES/JRC and SDGIndex procedures. The reports will be prepared after the English implementation has been reviewed.

The current repository documents the executable procedures in the root README. `english-migration.md` records the language/schema migration and official terminology sources. `legacy-schema.json` records renamed identifiers for compatibility and audit purposes.

## Methodological article (draft)

`SDG_Interlinkages_methodological_article.md` (source text), `.pdf` and `.docx` hold the current draft of *Beyond Co-movement: Performance Direction and Transmission Roles in SDG Interlinkage Networks*. It sets out the performance-based classification of links and the six interface roles, explains why the roles would matter for policy, and reports statistical tests (Section 7; details in `validity_sdgindex.md` and the `scripts/validity_*.py`, `raw_*.py` and `unsd_undirected.py` scripts) showing that correlations between the national indicator series currently available cannot support valid inference about interlinkages. Figure 1 is in `figures/`.
