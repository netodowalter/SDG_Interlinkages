# Methodological documentation

This directory holds the methodological article, the results of the validity tests and supporting documentation. Development of the package stopped in November 2026 (see the root README).

The current repository documents the executable procedures in the root README. `english-migration.md` records the language/schema migration and official terminology sources. `legacy-schema.json` records renamed identifiers for compatibility and audit purposes.

## Methodological article (draft)

`SDG_Interlinkages_methodological_article.md` (source text), `.pdf` and `.docx` hold the current draft of *Beyond Co-movement: Performance Direction and Transmission Roles in SDG Interlinkage Networks*. It sets out the performance-based classification of links and the six interface roles, explains why the roles would matter for policy, and reports statistical tests for Brazil, Finland and Norway (Section 7; details in `validity_sdgindex.md` and the scripts listed in the root README) showing that correlations between the national indicator series currently available cannot support valid inference about interlinkages. Figure 1, illustrated with Brazil, is in `figures/` and is drawn by `scripts/figure1_brazil.py`. The `.md` is the source text; the `.pdf` and `.docx` are exported from the online document.
